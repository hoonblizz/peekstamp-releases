# Peekstamp for macOS

Downloads of the Peekstamp desktop app for macOS. This repository holds only the signed, notarized app files. It has no source code.

Peekstamp shows game developers what can be read from their own pre-release Godot and Unity builds, and how to fix it.

- About, pricing and terms: https://slothlab.app/en/peekstamp
- Free quick scan in your browser, no install: https://peekstamp.slothlab.app
- Latest download: [Peekstamp.dmg](https://github.com/hoonblizz/peekstamp-releases/releases/latest/download/Peekstamp.dmg)

Needs an Apple silicon Mac (M1 or later) with macOS 13 or later. The Windows version is coming to the Microsoft Store.

## Check your download

Each release lists the SHA-256 of `Peekstamp.dmg`. To compare:

```
shasum -a 256 ~/Downloads/Peekstamp.dmg
```

The app is signed by Developer ID Application: Sloth Lab Inc. and notarized by Apple.
